# 🏠 Projeto Trybnb

Este projeto é um aplicativo Android desenvolvido em Java que simula uma plataforma de aluguel de acomodações, semelhante ao Airbnb. O objetivo é aplicar conhecimentos de desenvolvimento Android em um projeto prático, utilizando consumo de APIs e manipulação de dados dinâmicos.

## ✨ Demonstração

> A aplicação permite visualizar uma lista de acomodações com fotos, nomes, localização e valor. Os dados são dinâmicos e trazidos por uma API mockada. A interface oferece uma experiência agradável e intuitiva ao usuário, com um layout simples e funcional.

## 💡 Sobre

O **Trybnb** é um projeto de aplicativo Android criado para reforçar os conhecimentos adquiridos no curso da Trybe. A proposta é simular um catálogo de hospedagens, buscando os dados de uma API falsa e apresentando-os de forma dinâmica ao usuário.

O projeto foi desenvolvido individualmente, com foco em boas práticas de desenvolvimento, uso de componentes do Android Studio e integração com fontes de dados externas.

## 🧠 Habilidades Desenvolvidas

- Consumo de APIs REST com Retrofit
- Criação de layouts com XML
- Requisições assíncronas com Kotlin Coroutines
- Exibição de listas com RecyclerView
- Manipulação e exibição de dados JSON
- Uso de ViewBinding
- Navegação entre telas com `Intent`

## 🧪 Tecnologias Utilizadas

- Android Studio
- Java
- Retrofit
- ViewBinding
- RecyclerView
- MockAPI (API falsa para simular requisições)
- Glide (para carregar imagens)

## ⚙️ Funcionalidades

- Listagem de acomodações
- Exibição de imagem, nome, localização e valor
- Navegação entre telas
- Consumo de dados simulados por API
- Interface intuitiva e responsiva

## 🧭 Como Rodar o Projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/tryber/android-039-android-projeto-trybnb.git
   ```
2. Abra o projeto no Android Studio

3. Sincronize as dependências com o Gradle

4. Compile e execute o projeto em um dispositivo Android ou emulador
> A aplicação estará disponível para visualização no dispositivo/emulador.
